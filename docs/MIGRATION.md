# 엑셀에서 이관하기

> **현재 저장소의 데이터는 전부 더미입니다.** 아래는 실제 엑셀 마스터를 넣을 때의 절차입니다.

## 더미 데이터를 실제 데이터로 바꾸기

`index.html` 안에 데이터가 직접 들어 있습니다. 세 곳을 바꾸면 됩니다.

```javascript
const MASTER   = [ ... ];   // 업체마스터
const RAWVISIT = [ ... ];   // 방문일정
const VALS     = [ ... ];   // 역량값
```

`data/` 폴더의 `*.demo.json`과 같은 형식이므로, 엑셀을 그 형식의 JSON으로 변환해 붙여넣습니다.
필드 정의는 [DATA-MODEL.md](DATA-MODEL.md)를 참고하세요.

교체 후 앱 상단의 `데모 데이터 · 실제 업체 정보 아님` 문구를 지우고, **저장소를 Private으로 전환**하세요.

원본: `협력업체_통합관리_마스터.xlsx` (7개 시트, 업체 63개사)

|---|---|---|

| `2_조사항목DB` | 53 | **10개사 미등재** — 조사 제외인지 입력 누락인지 구분 필요 |

**연결 무결성은 양호합니다.** 조사항목DB·컨택로그·방문일정관리 어느 시트에도 마스터에 없는 업체ID가 없습니다.

### 먼저 고쳐야 할 것

1. **컨택로그 일자 채우기** — 없으면 "마지막 접촉이 언제인지"를 영원히 알 수 없습니다
2. **조사항목DB 미등재 10개사** — 빈 행으로라도 만들어 상태를 명시
3. **사업자번호 열 추가** — 매칭 정확도의 근본 해결책

## 이관 순서

### 1단계 — 항목 사전 확정 (반나절)

**이것이 안 되면 나머지는 다시 흩어집니다.**

`2_조사항목DB`의 18개 열을 보면서 항목코드로 정리합니다.
예를 들어 `보유 가마` 열은 `EQ01`(최대용량) + `EQ02`(대수)로 나뉩니다.

산출물: `data/dictionary.json`

### 2단계 — 사업자번호 + 법인/사업장 분리 (1~2일)

63개사 규모인 지금이 가장 저렴합니다. 100개사를 넘으면 비용이 3배가 됩니다.

- 사업자번호를 마스터 열로 추가
- 공장이 둘 이상인 업체를 사업장 테이블로 분리

### 3단계 — 기존 조사 데이터 이관

`2_조사항목DB` 53행을 세로형 `capability_values`로 풉니다.

```
가로 (지금)
업체ID | 보유가마      | CGMP     | 총CAPA
V002   | 2T, 1T*2      | 가능/보유 | 250만개/월

세로 (이관 후)
c    | k    | v    | s        | g | verified_at
V002 | EQ01 | 2    | 업체 회신 | B | 2026-06-30
V002 | EQ02 | 3    | 업체 회신 | B | 2026-06-30
V002 | CE01 | Y    | 식약처    | A | 2026-06-30
V002 | CP01 | 250  | 업체 회신 | B | 2026-06-30
```

**확인일(`verified_at`)을 반드시 채우세요.** 모르면 그 조사의 조사일을 씁니다.
이게 없으면 TTL이 동작하지 않습니다.

신뢰등급은 출처를 보고 부여합니다. 애매하면 `C`로 두세요. 나중에 올리면 됩니다.

### 4단계 — 기존 플래그 열을 조사로 전환

`Long-list` `우원3T가마` `방문진행` `기획요청` 4개 열을 조사 레코드로 바꿉니다.

| 플래그 | 건수 | → 조사ID |
|---|---|---|
| Long-list | 41 | S001 |
| 우원3T가마 | 16 | S002 |
| 방문진행 | 10 | S003 |
| 기획요청 | 0 | 폐기 |

`기획요청`은 0건이라 실제로 안 쓰인 열입니다. 이관하지 마세요.

전환 후 마스터에서 플래그 열 4개를 삭제합니다. **열 추가 방식은 여기서 끝납니다.**

### 5단계 — 방문일정관리 이관

`4_방문일정관리` 10행을 `visits`로 옮깁니다. 열 대응은 다음과 같습니다.

| 엑셀 | → | visits |
|---|---|---|
| 상태 | | `st` (일정협의→nego, 확정/재방문예정→plan, 방문완료→done) |
| 업체 요청일 | | `vend` |
| 협/생팀 가능일 | | `coop` |
| 품질보증팀 가능일 | | `qa` |
| 확정 방문일 | | `fix` |
| 시간(출발포함) | | `time` |
| 수배주체 / 수배사유 | | `picker` / `reason` |
| 방문결과/후속조치 | | `res` |

자유 텍스트(`장덕진·한아영 7/23~24`)는 그대로 두세요. 파서가 날짜를 추출합니다.

### 6단계 — L1 문진표 제작

구글폼 문항을 항목코드에 1:1 대응시킵니다. 회신 시트가 곧 `capability_values` 입력이 됩니다.

## 이관 중 원칙

- **행을 지우지 마세요.** 등록불가·방문취소도 이력입니다. 2년 뒤 같은 업체가 다시 후보로 올라옵니다
- **이전 값을 덮어쓰지 말고 이력에 남기세요.** 과거 자료의 오류 추적이 안 됩니다
- **모르는 값은 비워두세요.** 추정치를 넣으려면 반드시 등급 `D`로 표시하세요

---

## 병행 운영 기간

이관 직후 바로 엑셀을 버리지 마세요.

1. **2~4주 병행** — 엑셀과 새 도구에 같이 입력
2. 팀원들이 "항목코드 선택"에 익숙해지는 데 시간이 걸립니다
3. 재사용률이 올라가기 시작하면 엑셀을 읽기 전용으로 전환
4. 원본 엑셀은 **삭제하지 말고 아카이브**로 보관

## 절충안 — 전면 전환이 부담스러울 때

마스터를 지금 구조 그대로 두고, **자주 쓰는 항목 10개만** 먼저 세로형으로 빼는 방법이 있습니다.

```
EQ01 유화기 최대용량    EQ02 유화기 대수
EQ03 튜브 충전          EQ04 자 충전
EQ05 펌프 충전          EQ06 앰플·스틱
CE01 CGMP               CP01 월 캐파
CP03 리드타임           QA01 자체 시험실
```

실무 질문의 대부분을 이 10개가 덮습니다. 위험은 훨씬 적고, 효과는 전면 전환의 절반쯤 나옵니다.
6개월 써보고 판단해도 늦지 않습니다.
