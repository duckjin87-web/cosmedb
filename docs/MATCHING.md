# 매칭과 중복 판정

두 가지 서로 다른 판정이 있습니다. 헷갈리기 쉬우니 구분해서 보세요.

| | 매칭 | 중복 점검 |
|---|---|---|
| 묻는 것 | 이 업체가 마스터의 **어느 행**인가 | 이 업체를 **다시 조사해야 하나** |
| 대상 | 업로드된 외부 리스트 | 조사 대상으로 지정된 업체 |
| 결과 | 자동 연결 / 확인 필요 / 신규 | 기보유 / 재확인 / 신규 |

---

## 1. 매칭 — 어느 업체인가

### 왜 어려운가

**마스터에 사업자번호가 없으면** 확정 키가 없어 조합 판정에 의존할 수밖에 없습니다.
사업자번호를 확보하면 이 단계 전체가 단순 조회로 바뀝니다. **최우선 개선 과제입니다.**

### 비교 항목

업체명 · 대표자 · 주소지 세 가지를 씁니다.

업체명과 주소는 대개 채워지지만 **대표자명은 비는 경우가 많습니다.**
대표자가 비어 있으면 대조 항목이 하나 줄어들어 **확인 필요**로 떨어질 확률이 올라갑니다.
실제 마스터 이관 시 대표자명 채움률을 먼저 확인하세요.

### 업체명 정규화

표기 흔들림을 먼저 제거합니다.

```
제거 대상: (주) ㈜ 주식회사 (유) 유한회사, 모든 공백
대소문자 무시

(주)라온랩  →  라온랩
라온랩(주)  →  라온랩        ← 같은 업체로 인식
㈜ 라온 랩  →  라온랩
```

정규화 없이 비교하면 `(주)누리랩`과 `누리랩`이 다른 업체가 됩니다.

### 주소 비교

전체 문자열이 아니라 **정규화 후 앞 5자**로 부분 일치를 봅니다.

```
"경남 김해시 주촌면"  vs  "경남김해시주촌면골든루트로55"
   → "경남김해시" 포함  →  일치
```

번지까지 정확히 맞기를 기대하면 대부분 불일치가 나옵니다.

### 판정 규칙

일치한 항목 수를 셉니다. 기본 기준은 **2개 이상**입니다.

| 일치 항목 수 | 판정 | 처리 |
|---|---|---|
| 2개 이상 | 🟢 **자동 연결** | 마스터 업체ID 연결 |
| 1개 (업체명만 등) | 🟡 **확인 필요** | 후보 3건 제시, 사용자가 선택 |
| 0개 | 🔵 **신규** | 마스터 신규 등록 후보 |

화면 상단의 `2개 이상 / 3개 모두` 토글로 기준을 바꿀 수 있습니다.

- **2개 기준** — 자동 연결이 많아지지만 오연결 위험 존재
- **3개 모두** — 안전하지만 확인 대상이 크게 늘어남

실제 데이터로 양쪽을 눌러보며 팀에 맞는 기준을 정하세요.

### 실제 판정 예

앱에 들어 있는 샘플 리스트 7건 기준 (2개 이상 기준):

| 원본 | 판정 | 근거 |
|---|---|---|
| (주)누리랩 | 🟢 자동 | 업체명 · 대표자 · 주소지 |
| 가온화장품 | 🟢 자동 | 업체명 · 대표자 · 주소지 |
| 라온랩(주) | 🟢 자동 | 업체명 · 대표자 (괄호 위치가 달라도 인식) |
| 마루코스텍 | 🟢 자동 | 업체명 · 주소지 (대표자 공란) |
| 단아케미칼 | 🟡 확인 | 업체명만 (마스터에도 대표자 공란) |
| 한울코스텍 | 🔵 신규 | 마스터에 없음 |
| 우원정밀화학 | 🔵 신규 | 마스터에 없음 |

### 확인 필요 처리

후보 목록에서 직접 고르거나 신규로 등록합니다.

> **잘못 연결하면 두 조사의 이력이 한 업체에 섞입니다.**
> 확신이 없으면 신규로 등록하는 편이 낫습니다. 나중에 통합하는 것이 분리보다 쉽습니다.

## 2. 중복 점검 — 다시 조사해야 하나

조사 항목을 선택하면, 대상 업체마다 그 항목들의 보유 상태를 셉니다.

```
각 항목코드에 대해:
  값이 없음                          →  none
  값이 있고 유효기간 내              →  have
  값이 있으나 유효기간 경과          →  stale

업체 판정:
  none = 0 이고 stale = 0            →  🟢 기보유
  none = 0 (일부 stale)              →  🟡 재확인
  none > 0                           →  🔵 신규
```

| 판정 | 의미 | 조치 |
|---|---|---|
| 🟢 기보유 | 모든 항목에 유효한 답이 있음 | 물어볼 필요 없음 |
| 🟡 재확인 | 답은 있으나 기간 경과 | 기존값 첨부해 변경 여부만 확인 |
| 🔵 신규 | 답이 없는 항목이 있음 | 실제 조사 |

### 기보유도 강제로 빼지 않습니다

체크를 유지하면 조사에 포함됩니다. 이 경우:

- 기존 답이 **미리 채워진 상태**로 들어감
- 행이 흐리게 표시되어 구분됨
- "답은 있지만 이번엔 직접 확인하고 싶다"는 판단을 막지 않음

### 재사용률

```
재사용률 = (유효한 답을 이미 가진 칸) / (대상 업체 수 × 조사 항목 수)
```

조사 설계 화면에서 실시간으로 계산됩니다.
이 숫자가 조사를 반복할수록 올라가는 것이 시스템이 작동한다는 증거입니다.

## 3. 개선 계획

### 사업자번호 확보 (최우선)

수십 개사 규모면 하루 이틀 작업입니다. 확보 후에는:

```
사업자번호 일치  →  즉시 확정 매칭 (다른 항목 볼 필요 없음)
불일치           →  다른 업체
```

국세청 사업자등록상태 조회 API로 상호 + 대표자명 조합에서 역으로 채울 수도 있습니다.

### 유사도 매칭

현재는 포함 관계만 봅니다. 편집 거리(Levenshtein)를 넣으면
`가온랩` vs `가온랩코리아` 같은 사례를 후보로 올릴 수 있습니다.
다만 오탐이 늘어나므로 **확인 필요로만 분류**하고 자동 연결에는 쓰지 마세요.

### 법인 통합 이력

`가온랩코리아`가 기존 `가온랩`과 동일 법인으로 판명되면,
행을 지우지 말고 **통합 이력**을 남기세요. 두 업체명 모두 검색에 걸려야 합니다.
