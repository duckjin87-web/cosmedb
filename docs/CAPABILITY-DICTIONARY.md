# 역량 항목 사전

조사 항목의 **마스터 목록**입니다. 이 파일이 시스템의 뼈대입니다.

> 조사는 "새 열을 만드는 일"이 아니라 **이 사전의 빈칸을 채우는 일**입니다.
> 어떤 조사를 하든 같은 항목코드를 쓰면 값이 자동으로 한곳에 누적됩니다.

원본 데이터: [`data/dictionary.json`](../data/dictionary.json)

---

## 코드 체계

```
[그룹 2자][일련 2자]
 EQ  설비    Equipment
 CE  인증    Certification
 CP  캐파    Capacity
 FM  제형    Formulation
 QA  품질    Quality Assurance
 RK  리스크  Risk
```

새 항목이 필요하면 해당 그룹의 다음 번호를 씁니다. **기존 코드는 재사용하거나 의미를 바꾸지 않습니다.**
값의 의미가 바뀌면 새 코드를 발급하고 옛 코드는 폐기 처리합니다.

## 항목 추가 절차

1. 정말 재사용되는 항목인지 확인합니다. 한 번 쓰고 말 것은 조사 안의 **자유 항목**으로 두세요.
2. 그룹을 정하고 다음 일련번호를 발급합니다.
3. `data/dictionary.json`에 한 줄 추가합니다.

```json
{ "k": "EQ08", "n": "파우치 충전", "grp": "EQ", "gn": "설비",
  "t": "yn", "u": "", "ttl": 12 }
```

4. 수집 경로(L0/L1/L2)를 정하고, L1이면 문진표에 문항을 추가합니다.

### 자유 항목 vs 사전 항목

| | 자유 항목 | 사전 항목 |
|---|---|---|
| 만드는 곳 | 조사 생성 화면의 `＋ 사전에 없는 항목 추가` | `dictionary.json` |
| 재사용 | 안 됨 | 됨 |
| 중복 판정 | 대상 아님 | 대상 |
| 조건 검색 | 안 됨 | 됨 |

**같은 자유 항목이 세 번째 조사에서 또 나오면 사전으로 올리세요.**

## 커버리지 현황

현재 마스터 63개사 x 22항목 = 1,386칸 중 약 260칸이 채워져 있습니다(약 19%).

우선 채워야 할 항목:

1. **`CE01` CGMP** — 40개사 보유. L0 식약처 공표로 나머지도 자동 확보 가능
2. **`EQ01` `EQ02` 유화기** — 26개사. 수배 판단의 1차 기준
3. **`CP01` 월 캐파** — 문진표 필수 문항
4. **`EQ03`~`EQ07` 충전 타입** — 실무 질문의 대부분이 여기서 갈림

`RK01` 종업원 수는 국민연금 공시로 전량 자동 수집이 가능하므로 우선순위가 낮습니다.
